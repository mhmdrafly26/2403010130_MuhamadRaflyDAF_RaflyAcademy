Materi Pembelajaran Keamanan Siber

Setiap modul menyajikan penjelasan konsep, contoh ilustrasi simulasi yang aman, dan rangkuman inti untuk membantu pemahaman bertahap.

Topik 1

Introduction to Cyber Security

Keamanan siber adalah praktik melindungi sistem komputer, jaringan, dan data digital dari akses tidak sah, gangguan, atau kerusakan. Fokusnya mencakup manusia, proses, dan teknologi secara seimbang.

Contoh simulasi: Sebelum mempublikasikan aplikasi web, tim memeriksa pengaturan izin folder dan mematikan mode debug produksi.
Rangkuman: Keamanan siber bukan sekadar memasang perangkat lunak, melainkan disiplin berkelanjutan dalam mengelola risiko sistem dan data.
Topik 2

CIA Triad

CIA Triad terdiri dari Confidentiality (kerahasiaan informasi hanya bagi pihak berwenang), Integrity (keakuratan dan keutuhan data), serta Availability (ketersediaan sistem dan data saat dibutuhkan).

Contoh simulasi: Kontrol akses berbasis peran menjaga Confidentiality, checksum menjaga Integrity, dan pencadangan terjadwal mendukung Availability.
Rangkuman: Menyeimbangkan kerahasiaan, integritas, dan ketersediaan adalah fondasi evaluasi kebijakan keamanan sistem.
Topik 3

Networking Fundamentals

Komunikasi jaringan menggunakan alamat IP, port, dan protokol seperti TCP/IP, HTTP/HTTPS, serta DNS. Memahami alur paket membantu mengidentifikasi jalur akses dan pembatasan trafik.

Contoh simulasi: Layanan HTTPS umumnya berjalan di port 443 dengan enkripsi TLS, sedangkan SSH umumnya menggunakan port 22.
Rangkuman: Pemahaman alamat IP, port, dan protokol memudahkan konfigurasi firewall serta analisis konektivitas jaringan.
Topik 4

Linux Fundamentals

Banyak server dan perangkat keamanan berjalan di lingkungan Linux. Penguasaan izin berkas (read, write, execute), kepemilikan user/group, dan pemeriksaan log sangat penting untuk administrasi yang aman.

Contoh simulasi perintah: ls -la catatan.txt && chmod 640 catatan.txt
Rangkuman: Prinsip least privilege pada izin berkas dan pengguna membantu membatasi dampak kesalahan konfigurasi.
Topik 5

OWASP Top 10

OWASP Top 10 merupakan referensi kesadaran risiko keamanan aplikasi web yang paling sering ditemui, seperti kelemahan kontrol akses, kegagalan kriptografi, dan injeksi.

Contoh simulasi: Memverifikasi otorisasi pada setiap endpoint API agar pengguna biasa tidak dapat mengakses data milik pengguna lain.
Rangkuman: Mengacu pada OWASP Top 10 membantu memprioritaskan perbaikan celah paling berdampak pada aplikasi web.
Topik 6

SQL Injection

SQL Injection terjadi ketika input pengguna digabung secara langsung ke dalam string perintah SQL tanpa pemisahan parameter, sehingga input dapat memanipulasi struktur kueri.

Contoh simulasi mitigasi: Gunakan prepared statement / parameterized query alih-alih konkatenasi string input.
Rangkuman: Parameterized query adalah pertahanan utama untuk mencegah manipulasi kueri SQL dari input pengguna.
Topik 7

Cross-Site Scripting (XSS)

Cross-Site Scripting (XSS) terjadi ketika data yang dikendalikan pengguna ditampilkan di halaman web tanpa sanitasi atau konteks encoding yang sesuai, sehingga skrip berpotensi dijalankan browser.

Contoh simulasi mitigasi: Gunakan textContent saat menulis teks ke DOM dan lakukan context-aware encoding pada output HTML.
Rangkuman: Sanitasi dan encoding sesuai konteks tampilan mencegah input pengguna ditafsirkan sebagai skrip aktif.
Topik 8

Password Security

Keamanan kata sandi bergantung pada panjang/kompleksitas yang memadai, pencegahan penggunaan ulang sandi yang bocor, serta penyimpanan menggunakan fungsi hash adaptif dengan salt.

Contoh simulasi: Aplikasi menyimpan digest hash + salt unik per akun, bukan menyimpan kata sandi mentah.
Rangkuman: Jangan pernah menyimpan kata sandi dalam bentuk teks polos; gunakan hashing yang aman dan dukung autentikasi berlapis.
Topik 9

Cryptography Fundamentals

Kriptografi melindungi kerahasiaan dan integritas data melalui enkripsi simetris (satu kunci bersama), enkripsi asimetris (pasangan kunci publik dan privat), serta fungsi hash satu arah.

Contoh simulasi: Enkripsi melindungi isi pesan saat transit/penyimpanan, sedangkan hash membantu memeriksa keutuhan berkas.
Rangkuman: Pilih mekanisme kriptografi sesuai kebutuhan (enkripsi untuk kerahasiaan, hash untuk verifikasi integritas).
